# Rekap Bab 152 — Azure Heaven Creation Sect (3)

## Ringkasan

Seo mempelajari susunan metode cultivation Azure Heaven Creation Sect dan mendatangi Scripture Pavilion serta Five Elements Hall untuk mencari dasar latihan. Setelah menyaksikan metode latihan lima unsur yang ekstrem, ia hendak pergi, tetapi dikepung para murid senior di Earth Path Body Training Hall dan meraih Starting Form untuk mencoba meloloskan diri.

## Events

- **ev-152-01 — Penjelasan kurikulum sekte:** Azure Tiger Saint menjelaskan bahwa Azure Spirit Striking Origin Technique berfokus pada serangan dan daya ledak, Starlight Protecting Void Body pada pertahanan dan kestabilan, sedangkan Five Elements Enduring Origin Scripture pada daya tahan, penyembuhan, dan regenerasi. Ketiganya adalah bagian awal, tengah, dan akhir Azure Spirit Starlight Quintessence Great Method. Murid sekte biasanya mempelajari Five Elements Enduring Origin Scripture terlebih dahulu, kemudian Starlight Protecting Void Body, Azure Spirit Striking Origin Technique, lalu metode gabungannya. Karena mengamati potensi Seo, Azure Tiger Saint langsung memulai pengajarannya dengan metode bagian tengah.
- **ev-152-02 — Rencana latihan Oh Hyun-seok:** Azure Tiger Saint menyatakan Oh Hyun-seok akan segera diajari Azure Spirit Starlight Quintessence Great Method karena Unique Holy Body. Sebelum mengajarinya teknik, ia akan menguji ketangguhan Oh melalui sparring dan pemulihan berulang.
- **ev-152-03 — Scripture Pavilion dan Cheon Hoon:** Seo mencari Five Elements Enduring Origin Scripture di Scripture Pavilion dan bertemu Cheon Hoon, murid One-Cloud yang menopang bangunan untuk latihan. Cheon Hoon menunjukkan lokasi lima kitab dasar dan membolehkan Seo menyalinnya, tetapi metode lain dilindungi dan mensyaratkan kemenangan adu panco melawannya. Ia menyarankan Seo meminta bantuan di Five Elements Hall.
- **ev-152-04 — Kunjungan ke balai latihan lima unsur:** Seo mempelajari inti kelima metode dasar, lalu berkeliling balai latihan. Di Fire Path, para murid berlatih dalam api dan lava; di Metal Path, mereka menghadapi Gold-Tooth Sharks; di Water Path, mereka dilatih menahan tekanan air; di Wood Path, mereka dipukuli dengan pukulan yang menyembuhkan sekaligus meregenerasi; dan di Earth Path, para murid tingkat bawah berlatih dengan dikubur lalu memanjat keluar. Seo memutuskan sebaiknya kembali berlatih Starlight Protecting Void Body.
- **ev-152-05 — Terkepung di Earth Path Hall:** Para murid senior mengenali Seo sebagai murid langsung Sang Pendiri, menghalangi jalan keluarnya, dan menyerbu saat ia hendak pergi. Seo membaca niat mereka sebagai jalur dan lintasan, lalu meraih Starting Form untuk mencoba kabur. Hasilnya belum ditampilkan.

## Character developments

- **Seo Eun-hyun:** Menyadari bahwa metode tengah yang diajarkan Azure Tiger Saint bukan keseluruhan metode gabungan. Ia mencari fondasi Five Elements Enduring Origin Scripture, mengingat batas bakatnya sendiri, dan mengamati latihan lima unsur sebelum berusaha menghindari sparring paksa.
- **Azure Tiger Saint:** Menjelaskan urutan kurikulum sekte serta alasan memulai Seo dari Starlight Protecting Void Body. Ia juga berencana menguji ketangguhan Oh Hyun-seok melalui sparring.
- **Oh Hyun-seok:** Akan menjalani latihan sparring untuk menguji daya tahannya sebelum mulai menerima metode yang benar; ia belum muncul langsung dalam adegan bab ini.
- **Cheon Hoon:** Murid One-Cloud yang menjadi pustakawan Scripture Pavilion dan melatih tubuh bagian atas dengan mengangkat bangunannya.
- **Cheon Hae:** Murid perempuan berotot yang menyelam ke lava untuk menarik murid Two-Cloud keluar.

## Relationship changes

- Tidak ada perubahan hubungan yang ditegaskan dalam bab ini.

## State changes

- Seo memperoleh dan mempelajari inti lima metode dasar Five Elements Enduring Origin Scripture.
- Seo menyaksikan praktik latihan di kelima balai Five Elements Hall dan belum tampak memulai latihan di sana.
- Bab berakhir ketika Seo mulai mencoba melarikan diri dengan Starting Form; hasil upaya itu belum diketahui.

## New facts

- Azure Heaven Creation Sect menggolongkan murid berdasarkan jumlah awan pada pakaian: Five-Cloud untuk murid baru, Four-Cloud untuk Qi Refining, Three-Cloud untuk Qi Building, Two-Cloud untuk Core Formation, dan One-Cloud untuk Nascent Soul. Murid One-Cloud dapat menantang untuk posisi tetua; para tetua Heavenly Being mengenakan jubah biru tanpa awan.
- Seo dan Oh Hyun-seok, meski ranah cultivation mereka setara murid Five-Cloud, diizinkan menyandang pola Two-Cloud karena status sebagai murid langsung Azure Tiger Saint.
- Five Elements Enduring Origin Scripture terdiri atas metode Fire, Water, Wood, Metal, dan Earth Path.
- Metode lima unsur di balai latihan menuntut ketahanan tubuh melalui api dan lava, gigitan ikan, tekanan air, pukulan yang memulihkan tubuh, serta tekanan tanah.

## Claims / uncertain information

- Cheon Hoon mengatakan kitab dasar Five Elements Enduring Origin Scripture boleh disalin untuk dibawa; metode lain di Scripture Pavilion dibatasi dan memerlukan ujian adu panco dengannya.
- Menurut Cheon Hoon, banyak senior di Five Elements Hall pernah memulai dari Five Elements Enduring Origin Scripture dan bersedia membantu; Seo belum meminta atau menerima bantuan mereka.
- Seo belum diketahui berhasil atau gagal meloloskan diri dari para murid yang mengepungnya.

## New terminology

- **Azure Spirit Striking Origin Technique:** Bagian awal metode gabungan; berfokus pada serangan dan daya ledak.
- **Starlight Protecting Void Body:** Ejaan judul metode yang muncul dalam sumber bab ini; bagian tengah, berfokus pada pertahanan dan kestabilan. Bab 151 memakai variasi nama “Starlight Protective Void Body”; perbedaan ejaan sumber dipertahankan, bukan dinormalisasi.
- **Five Elements Enduring Origin Scripture:** Bagian akhir metode gabungan; berfokus pada daya tahan, penyembuhan, dan regenerasi, terdiri atas lima metode unsur.
- **Azure Spirit Starlight Quintessence Great Method:** Metode gabungan asli yang ditransmisikan setelah murid menguasai metode-metode bagiannya.
- **Starting Form:** Form yang diraih Seo pada akhir bab saat berusaha mencari jalan keluar.
