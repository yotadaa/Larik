# Panduan Gaya

| Catatan | Gunakan prosa Indonesia yang luwes dan setia pada makna, suara, serta urutan adegan sumber. |
| Catatan | Pertahankan nama diri dan nama teknik/istilah khusus dalam bentuk bahasa Inggris sumber; jabatan umum diterjemahkan konsisten. |
| Catatan | Gunakan tanda petik ganda untuk dialog, tanda petik tunggal untuk pikiran langsung, dan `---` untuk jeda adegan bila muncul di sumber. |
| Catatan | Jangan menambahkan penjelasan ke dalam narasi. |
| Catatan | Pertahankan istilah kultivasi kanonis dari glosarium; jangan menambahkan penjelasan ke dalam narasi. |
| Catatan | Metadata sumber yang tidak tersedia tidak boleh dikarang. |
| Catatan | Pertahankan variasi ejaan nama teknik khusus bila sumber bab berbeda; catat perbedaan tanpa normalisasi diam-diam. |
