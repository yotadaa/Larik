## Prosedur wajib sebelum memperbarui metadata

1. Baca file target sepenuhnya dan catat header serta ID/baris terakhir.
2. Tentukan apakah perubahan append-only atau koreksi historis; jangan menulis ulang file untuk menambah satu bab.
3. Untuk penambahan kecil, gunakan `edit` setelah tabel. Untuk rekonstruksi massal, pastikan semua isi pengganti lengkap dan bersumber sebelum `write`.
4. Sesudah perubahan, hitung baris data dan ID, cek duplikasi serta referensi silang, dan pastikan seluruh ID lama yang seharusnya tetap ada masih tercatat.
5. Jalankan dry-run migrator v2 sebelum melaporkan selesai; catat error validasi, jangan mengabaikan mismatch.
6. Jika sumber tidak mendukung kepastian, gunakan status epistemik sesuai bukti dan dokumentasikan konflik di sini.
