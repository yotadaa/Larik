# Chapter Translation QA Checklist

## Metadata

- [ ] Novel title is correct.
- [ ] Chapter number is correct.
- [ ] Chapter title is correct.
- [ ] Target language is correct.
- [ ] Filename follows project convention.

## Completeness

- [ ] Every source paragraph has been accounted for.
- [ ] Every dialogue turn has been accounted for.
- [ ] Scene breaks are preserved.
- [ ] System messages, letters, signs, poems, or embedded text are preserved appropriately.
- [ ] No content was accidentally summarized.

## Meaning

- [ ] Negation is preserved.
- [ ] Modality is preserved (`may`, `must`, `should`, uncertainty, possibility).
- [ ] Temporal order is preserved.
- [ ] Subject/object relationships are correct.
- [ ] Numbers, ranks, quantities, and measurements are correct.
- [ ] Intentional ambiguity remains ambiguous.

## Canonical Consistency

- [ ] Character names match `characters.md`.
- [ ] Locations match `locations.md`.
- [ ] Recurring terms match `glossarium.md`.
- [ ] System/rank terminology matches `terminology.md`.
- [ ] Titles and honorifics follow `STYLE_GUIDE.md`.

## Character Voice

- [ ] Formality matches the speaker.
- [ ] Social hierarchy is preserved.
- [ ] Slang/roughness/politeness remains character-specific.
- [ ] Internal thoughts are distinguishable from spoken dialogue.

## Literary Quality

- [ ] Target-language prose reads naturally.
- [ ] Source syntax has not been copied mechanically.
- [ ] Metaphors retain their function.
- [ ] Emotional intensity is not exaggerated or weakened without reason.
- [ ] Repetition that is intentional is retained.
- [ ] Repetition caused only by awkward translation has been cleaned up.

## Continuity

- [ ] Pronouns are consistent.
- [ ] Character knowledge is not accidentally expanded.
- [ ] Item ownership is consistent.
- [ ] Current injuries/status conditions are consistent.
- [ ] Location and time progression make sense.
- [ ] Relationships and aliases are consistent.

## Markdown

- [ ] Frontmatter is valid.
- [ ] Main heading is correct.
- [ ] Navigation links are valid.
- [ ] No accidental code fences exist.
- [ ] Paragraph spacing is readable.
- [ ] Chapter notes contain no story prose that belongs in the translation.

## Memory Updates

- [ ] Recap written.
- [ ] New recurring terms added to glossary.
- [ ] New character facts added when useful.
- [ ] New locations added when useful.
- [ ] Complex system terms added to terminology file.
- [ ] Continuity constraints updated.
- [ ] Chapter index updated.
- [ ] Important uncertainty logged in QA log.
