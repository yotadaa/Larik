## Runtime architecture check

The implementation keeps the established no-runtime-inference rule:

- Markdown parsing and normalization happen in the migration/sync step;
- canonical reusable knowledge is stored in D1;
- D1 applies spoiler/review filters before JSON serialization;
- browser code handles visualization/layout;
- the Worker does not scan the whole Markdown corpus or infer relationships from prose per request.
